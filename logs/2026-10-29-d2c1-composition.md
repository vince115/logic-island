## 1. 構圖與視覺層級（本輪重點）

| 項目 | 做法 |
|---|---|
| 地表連續 | 同高度、同類地面（草地／草原／廣場、森林、沙地、岩石）的相鄰地塊之間不再畫邊框，地表連成一片。每格保留 ±2.5% 的淡色差，接縫帶再暗 1.5%，近看仍看得出六角格，遠看不會像棋盤。只有地面類型或高度改變的地方保留邊框與崖壁 |
| 中央廣場 | 中央地塊上鋪一個圓形、略為墊高（0.07）的廣場：深色路緣、內圈紋路、中央方尖碑導覽柱（頂端用島嶼代表色），4 塊指標分別指向碼頭、工坊、燈塔與往資料結構島的橋。廣場外圈有 6 段矮樹籬，避開每條道路的入口。所有道路都從廣場中心出發，路面從廣場邊緣下方進入 |
| 空間敘事 | 主動線「碼頭 → 廣場 → 燈塔」路寬 0.6（其他道路 0.5），沿路有 9 盞路燈，左右交錯。燈塔步道延伸到燈塔門前（GLB 實測：基座前緣 z 0.90，門 Anchor 在 z 0.78），終點是一圈石鋪平台；工坊門前鋪一塊前庭 |
| 地標構圖 | 工坊後方 (2, -1) 種一片樹林，深色樹冠襯出藍色屋頂；燈塔在北側岬角，旁邊是北方森林與西側丘陵；碼頭在西南海灣，背後是森林 |
| 丘陵 | 西側丘陵合併成少數幾層：0.6 台地（與燈塔岬角同高）、1.2 肩部、1.8 岩石山頂（D.2b 是 0.3 一階、最高 0.9），遠景可以看出山形，也不會變成一格一格的階梯。山頂放 2 塊岩石 |
| 森林 | 改成群聚：中心密、邊緣疏，少量小樹延伸到相鄰草地，沒有孤立的樹（每棵樹 0.9 內至少有 2 棵）；高地以針葉樹為主。全世界 83 棵（D.2b 是 54 棵） |
| 鏡頭 | 改依島嶼實際輪廓與建築高度取景，不再用外接方框（斜向排列時方框角落都是空海）。聚焦倍率桌機 27.9 → 36.9、手機 13.8 → 18.2，建築約大 32% |
| 全景名牌 | 放在每座島背向其他島的外側海岸外。桌機是往外延伸的名稱膠囊，手機維持 D.2b 的彩色圓點。E2E 驗證名牌不蓋住任何地塊中心，也不超出畫面 |

## 2. 海岸與海面（第一版保留下來的部分）

- **沙灘：** 沙灘地塊（shore／sand）與指定的崖腳地塊，從邊緣往海裡鋪一段斜坡沙灘（乾沙 22°、濕沙 10°）；凸角處做成圓弧，水線有白色浪花。
- **崖腳沙灘（`cliffBeaches`，只影響渲染）：** (2, 1)、(3, 0)、(-1, 2)、(3, -2)。南岸與東岸因此是崖壁、沙灘、海灣交替，不是整圈等高的牆。
- **岩壁：** 分成 3 欄、多列，內側兩欄往外傾，越往下越寬，不會有倒懸的面；水線附近顏色較深，像濕岩。
- **保持平直的岩壁：**
  - 橋頭地塊的每一邊都是岩岸，不放沙灘；
  - 碼頭那一邊、坡道下方的台階、沙灘後方的岩壁都不外傾，確保橋、碼頭、坡道與道路的接合跟 D.2b 相同。
- **海面：**
  - 依離陸地的距離，從淺色漸層到深色，水裡不再出現六角形輪廓；
  - 這層顏色烘成一張小貼圖，貼在單一四邊形上。第一版用 1.8 萬個三角形的網格，連續渲染時幀率掉一半。

## 3. 撤回的項目（因優先順序調整）

- **零散裝飾（草叢、花、卵石、漂流木、灌木）：** 程式與渲染元件都已刪除。
- **新光照：** 「natural」預設與 2048 陰影貼圖已刪除。光照維持 D.2b 的 `contrast`。

37 格的地塊集合、座標、中央廣場、沙灘地塊、三棟 GLB 建築的位置、兩座橋、工坊道路都沒有改。

**共用元件的改動（都是可選用參數，A2 與 19 格不受影響）：**

**不變性驗證（計算結果的 hash，與 `fa3a9a9` 比較）：**

## 5. 效能（隔離副本，production build，headless Chromium，Apple GPU／ANGLE）

| 指標 | D.2b（`fa3a9a9`） | D.2c-1 |
|---|---|---|
| draw call 全景 | 80 | 81 |
| draw call 聚焦 | 75（手機 71） | 64 |
| 三角形 | 50,316 | 74,042 |
| instance 數 | 149 | 215 |
| 投射陰影的物件 | 37 | 38 |
| 單次 render CPU 時間 | 約 0.8 ms | 約 0.8 ms |
| 閒置時的 rAF 請求（2 秒） | 0 | 0 |
| 連續渲染幀率，桌機（5 次中位數） | 32.8 | 21.4 |
| 連續渲染幀率，手機尺寸 | 41.9 | 31.0 |

- **閒置成本：** 場景只在畫面變動時 render（`frameloop="demand"`），閒置時兩版都沒有成本。連續渲染只發生在鏡頭轉場與雙指縮放時。
- **成本來源（關閉單項後的桌機中位數）：**

  | 狀態 | fps |
  |---|---|
  | 全開 | 16.7 |
  | 海面換回 D.2b | 17.8 |
  | 地形換回 A2 | 17.8 |
  | 不畫自然元素（樹、岩石、廣場） | 24.3 |
  | 用外接方框取景 | 18.9 |
  | 地形不投射陰影 | 17.3 |
  | 全部換回 | 30.4 |

  主要成本是樹木數量。第一版有 123 棵樹、111 塊岩石，連續渲染只有 D.2b 的一半（16.4／23.3）；調整成 83 棵樹（42 棵是 138 面的針葉樹）、72 塊岩石後，回到 21.4／31.0。
- **測量方式：** 這輪把連續渲染幀率獨立測量，不再接在 `gl.finish` 迴圈後面。5 次結果的差距不到 1.3 fps，比 P1-20 記錄的 rAF 數字穩定得多；但仍是 headless 數字，不代表真機。真機效能屬於 D.3。

**新增的單元測試：**

- **地形連續性：**
  - 每格頂面都是完整的六角形，頂點都在格線上；
  - 每個落差或海岸邊恰好一面牆，牆頂在六角邊上，角落欄在六角頂點上；
  - 每個角落各面牆的高度範圍連續、沒有縫；
  - 台階牆只往低處傾、不超過 0.16；
  - 沒有朝下的面；
  - 只有同高、同類地面的相鄰格之間沒有邊框。
- **道路與橋接合：**
  - 坡道與 A2 地形逐一相同；
  - 平路段落在其下地塊的高度；
  - 每段坡路都對應地形上的一個坡道；
  - 橋頭地塊與碼頭邊不放沙灘、岩壁平直；
  - 沙灘不碰橋頭的角落，也不會高過任何陸地。
- **廣場與動線：**
  - 道路都從廣場中心出發；
  - 每條路一塊指標，方向對準終點；
  - 樹籬不壓到道路；
  - 路燈在同高的地面上，離道路與建築都夠遠；
  - 只有主動線加寬；
  - 燈塔步道依 GLB 數值停在門前，平台正好接到步道終點；
  - 工坊前庭在門口與門前點之間。
- **自然元素：**
  - 沒有孤立的樹，中心地塊比邊緣密；
  - 樹離落差邊緣與真實 GLB 建築外框夠遠；
  - 崖腳岩石在水中、遠離橋與碼頭，山頂岩石在岩石地塊上。
