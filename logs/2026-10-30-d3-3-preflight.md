## 2. 實作

- **同一套 renderer 與設定：** `sceneOptions(layout, preset)`（`hex-scene-presets.ts`）是唯一組合場景設定的地方；候選頁用 `sceneOptions(islandsWorld, production)`，37 格實驗室用 `sceneOptions(scalePrototypes['37'], lab)`。單元測試鎖住「實驗室＝候選頁＋探針」。
- **正式 Explorer：** `islands-world-explorer.tsx` 只負責把正式文案、世界與 preset 交給共用的 `HexWorldExplorer`，沒有另一套實作。
- **文案由頁面提供：** 共用 Explorer 新增 `copy`（section 名稱、工具列標題與小字、地圖標題、提示、canvas 名稱、載入文字）與 `footer`。預覽頁不傳，沿用原本的 D.2 文字；`next/dynamic` 的載入畫面透過 context 取得頁面文案。
- **正式文案：** 取自目前 `/islands`：「Logic Islands 邏輯群島地圖」、「群島全景」、「LOGIC ISLANDS ARCHIPELAGO／每一座島，都是理解的新起點。」、canvas「Logic Islands 三座學習島嶼，亦可使用場景外的清單導航」、「正在準備邏輯群島…」。頁首去掉「PROTOTYPE 02A」。
- **保留：** 3D／清單切換、BFS 頁面附註、島嶼／教材數量（「3 座主題島嶼 / 5 份教材入口 / 一步步建立理解」，由資料計算）。
- **移除：** 測試控制（19／37 格、回到正式群島地圖）、裝飾性羅盤、重複標語「THINK · VISUALIZE · CODE」（網站頁尾已有）。
- **Hover：** 新的場景選項 `hover`（只在 `production`，實驗室繼承）。滑鼠移到可點的地方——另一座島的地形，或已聚焦島嶼的目標建築——畫布顯示 pointer 游標，該島的 HTML 名牌點亮（邊框與外框改用島色）。**不新增任何 3D 物件或材質**；只在滑鼠移動時對三塊地形與聚焦島的建築做 raycast（CPU），觸控不觸發。
- **手機工具列：** 頁面沒有額外工具列連結時，≤430 px 的工具列固定一行：島名不換行（必要時省略號），小字標籤讓位。預覽頁與實驗室有額外連結，維持原本的換行。
- **場景 `label` 改為必填：** canvas 名稱只由 Explorer 的文案決定，移除場景內重複的預設字串。

## 3. Skip Link

「跳至主要內容」是全站 `layout.tsx` 的元件：`position: fixed; top: -80px`，只有 `:focus` 時 `top: 5px`。驗證結果：

- 載入後、滑鼠點擊或觸控聚焦島嶼後、畫布捲入畫面後，都在視窗之外；
- 第一次 Tab 聚焦並顯示，下一次 Tab 移開後隱藏（候選頁與舊版，桌機與手機）。

D.3-2 手機對照圖中出現在地圖上的「跳至主要內容」是**截圖造成的假象**：那些是比視窗高的元素截圖，Playwright 會擷取視窗以外的範圍，而固定在視窗上方 80 px 的 Skip Link 正好落在擷取範圍內。使用者在手機上看不到。本輪截圖改為從頁首開始的整頁截圖，不再出現。

另一個細節：減少動態效果（reduced motion）時，全站樣式讓所有屬性變化有 0.01 ms 的 transition，Skip Link 的位置在下一幀才更新；測試因此輪詢檢查，使用者看不出差別。

## 5. 渲染成本

D.3-0 方法（`perf/world.perf.ts`），SwiftShader，3 輪輪流量測的中位數。37 格實驗室使用 `lab` preset（＝production＋探針）。

| 指標 | 現行 `/islands` 桌機 | 候選頁 桌機 | 實驗室 桌機 | 現行 `/islands` 手機 | 候選頁 手機 | 實驗室 手機 |
|---|---|---|---|---|---|---|
| 全景 主畫面 draw call／三角形 | 146／12,086 | **43／28,569** | 43／28,569 | 146／12,086 | **43／28,569** | 43／28,569 |
| 聚焦 主畫面 draw call／三角形 | 82／10,984 | **26／38,339** | 26／38,339 | 45／10,472 | **26／38,339** | 26／38,339 |
| 陰影 draw call（每幀） | 112 | **0** | 0 | 112 | **0** | 0 |
| 鏡頭飛行 FPS | 60 | 49.0 | 49.2 | 60 | 59.6 | 59.4 |
| 飛行幀間隔 p95（ms） | 16.7 | 33.4 | 33.4 | 16.7 | 16.8 | 16.8 |
| 首幀（ms） | 820 | 1,403 | 1,404 | 823 | 1,387 | 1,406 |
| GLB 就緒（ms） | 1,375 | 2,055 | 1,919 | 1,337 | 2,032 | 2,844 |

- **候選頁與 production preset 一致：** 全景與聚焦的 draw call、三角形、陰影 draw call 與實驗室逐項相同；飛行 FPS、首幀在誤差內（GLB 就緒受機器負載影響，各輪差距達數百 ms）。單元測試另外鎖住兩者的場景設定只差探針。
- 「飛行中每幀 draw call 中位數」手機上候選頁 37～43、實驗室 32：這是全景（43）與聚焦（26）之間各幀混合後的中位數，隨每段飛行畫了幾幀而變，現行 `/islands` 同樣在 85～120 之間跳動（D.3-0 起的紀錄皆如此），不是成本差異。
- Hover 不增加 draw call：只在滑鼠移動時對三塊地形與聚焦島的建築做 raycast。
- 與現行 `/islands` 的差距（P1-26）維持 D.3-0 的結論；是否切換由 D.3-4 真機結果與產品決定。

## 6. D.3-4 真機驗收規格（待驗收標準，未量測、未通過）

> 以下門檻只是 D.3-4 的待驗收標準草案，需在 D.3-4 批准時確認。本輪沒有真機數據，**不宣稱已通過**。

### 6.1 每次量測要記錄

| 項目 | 內容 |
|---|---|
| 裝置 | 型號、OS 版本、是否低耗電模式（須關閉）、電量（> 50%）、量測前閒置 2 分鐘降溫 |
| 瀏覽器 | iPhone：Safari（版本）；Android：Chrome（版本）。另記錄是否私密分頁 |
| 網路與建置 | 同一 Wi-Fi；Mac 上的 production build（`next build`＋`next start -H 0.0.0.0`，不用 3100 埠） |
| 畫面 | 視窗 CSS 尺寸、`devicePixelRatio`、canvas 實際 DPR（`canvas.width / canvas.clientWidth`；兩版都限制在 1～1.5） |
| 首幀 | 從導航開始到第一次畫到螢幕（預設 framebuffer 的第一個 draw call）的毫秒數 |
| GLB 就緒 | 到基礎程式島名牌 `data-model-source="glb"` 的毫秒數 |
| FPS | 鏡頭飛行（清單選基礎程式島 →「返回全景」）時的 FPS 中位數，以及幀間隔中位數與 p95；雙指縮放時的 FPS |
| 閒置 | 不操作時不重畫（rAF 0） |
| 觸控 | 點島嶼名牌聚焦、地點清單、雙指縮放、返回全景、清單模式：逐項通過／不通過 |
| 新舊對照 | 同一台裝置、同一次連線，`/islands`（舊版）與 `/islands/candidate`（新版）交錯量測，各 3 輪；第一輪冷快取（私密分頁），其後熱快取 |

### 6.2 量測方式

- Android：Chrome 遠端偵錯（`chrome://inspect`）。D.3-0 的 `perf/world.perf.ts` 以包裝 WebGL draw 函式計數，同一套儀器可經 CDP 連到手機上的 Chrome；連線方式需在 D.3-4 補上，現有 harness 只啟動本機瀏覽器。
- iPhone：Safari Web Inspector 的 Timelines（Rendering Frames）讀幀時間與首幀；`devicePixelRatio` 與 canvas DPR 由 console 讀取。
- 兩條路由都不依賴探針，所以舊版與新版用同一方法量測。
