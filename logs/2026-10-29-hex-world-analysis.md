# 2026-10-29 六角聚落世界架構分析與 D.2 拆分

## 背景

D.1 的工程整合被接受，但三座分離浮島的畫面不符合產品視覺構想。目標改為六角形地塊組成、以橋樑和道路相連的聚落世界，等距視角，未來可顯示未解鎖狀態。使用者提供的參考圖：明亮的 low-poly 島塊、白色崖邊、綠色地表、碎石步道、木棧橋與石拱橋、燈塔與路燈。

本篇為分析紀錄，不含實作。

## 1. v2.1 GLB 可重用範圍

| 可重用（獨立 pivot 的子樹） | 不可重用（整島合併 mesh） |
|---|---|
| `Building_Workshop`（約 3.0×3.2） | `CliffRock`、`GrassPlatforms`、`Weathered_Cliff_Outcrops` |
| `Landmark_Lighthouse`（約 1.8×1.8） | `Signs_and_LampFrames`、`Route_LampGlow`（橫跨全島） |
| `Dock_Entry` | `Coast_Boulders`、`Shrubs_and_Wildflowers`、`Central_Low_Planting` |
| `Tree_001`～`Tree_005` | `Path_Main`、`Stairs_Upper`、`Bridge_Gully`、`Coastal_Ramp` |

- Anchor 掛在 `Anchors` 群組，不在建築底下。若要隨建築搬移，需換算成相對座標：
  - 工坊：(0.3, 0.15, 1.55)
  - 燈塔：(0, 0.2, 0.78)
  - 碼頭：(0, 0.2, 0.3)
- `Anchor_Route_Exit` 可作為基礎島的橋頭接點（對應 Phase E 的島嶼關聯）。
- 全島只用 2 種材質，地塊可沿用同一調色盤。
- 限制：
  - 燈塔原坐在高度 1.45 的平台上，工坊坐在 0.65，放到平坦地塊需另做底座。
  - 路燈併在全島 mesh 裡，拆不出來。

## 2. 方案比較

| 面向 | A：R3F 程式地塊＋GLB 建築 | B：Blender 六角組件 GLB | C：六角大地圖＋放大後顯示 D.1 整島 |
|---|---|---|---|
| 修改成本 | 中（約 5～7 個新模組，不需新美術） | 高（A 的程式＋整套建模與驗收） | 中高（A＋場景切換） |
| 視覺品質 | 中（地塊規則、建築細緻） | 高（同一套美術語言） | 遠景中、近景高，切換時斷裂 |
| 效能 | 好（地塊 instancing） | 中（需合併或 instancing） | 遠景好，近景同 D.1 |
| 可維護性 | 高（新增島只改資料） | 中（每種地形都要建模） | 中（兩套場景） |

## 3. 決議（2026-10-29，使用者）

1. 原則採用 **A＋**：R3F 程式生成六角地塊，重用現有 GLB 建築，日後可換成 Blender 六角組件。
2. 原 D.2 拆成 **D.2a／D.2b／D.2c**，分階段批准；本次只批准 D.2a。
3. D.2a 是六角聚落地圖原型，要求如下：
   - axial (q, r) 座標、flat-top 地塊；
   - 三座聚落，每座先用 7 格，但資料結構要允許不同格數；
   - 兩條橋樑，必須接在地塊邊緣；
   - 桌機與手機都能用的等距鏡頭；
   - 只用程式生成的簡單材質。
4. D.2a 不做的事：
   - 不建中央島、APCS 島、AI 島；
   - 不做解鎖判定或任何 E～J 功能；
   - 不拆 GLB 建築、不改 Anchor。
5. 以獨立的 Hex World 預覽模式實作，與正式 `/islands` 隔離；D.0、D.1 成果保持不變。

D.2b、D.2c 的實際內容等 D.2a 視覺方向確認後再定義。依分析，可能包括：

- 把 GLB 建築放上地塊；
- 鏡頭與光照調整；
- 決定是否取代 `/islands`。

## 4. 風險

- 程式地塊與 GLB 建築風格不一致。
- 燈塔平台高度和地塊比例不合。
- 島數增加後 draw call 與 HTML 標籤負擔變大。
- 容易提前做到 Phase E 的範圍。
- E2E 點擊位置需要重新校準。
- 六角地塊是通用的版面形式，但不照搬 Catan 特有的資源種類、數字標記、配色與美術。
