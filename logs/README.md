## 撰寫規則

- 繁體中文；技術名稱、路徑、指令、commit hash 保持原文。
- 每篇寫明：授權範圍、做了什麼、證據（指令輸出、SHA、hash）、沒做什麼、待決事項。
- 不寫入 API Key、Token、密碼等秘密值。
- 不改寫舊紀錄；狀態變更另寫新篇或在文末加日期註記。
