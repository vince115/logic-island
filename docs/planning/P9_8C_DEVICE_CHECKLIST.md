# P9.8c 實機驗收清單（iPhone Safari／Android Chrome）

> 狀態：**Pending（尚未執行）**。自動化測試只用 headless Chromium 的手機模擬，不能代替本清單。
> 對象：P9.8c Shared Canvas（`/` 與 `/cs` 共用一個 WebGL Canvas）。

## 0. 準備

- **需要的建置**：`LOGIC_ISLAND_P9_PROTOTYPE=1` 與 `LOGIC_ISLAND_P9_SHARED_CANVAS=1` 同時設定。Production 永遠關閉，不可用正式網址測試。
- **兩種取得方式**（都要由使用者決定）：
  - **區域網路**：在 Mac 上用兩個旗標建置並執行 `next start --hostname 0.0.0.0 --port <port>`，手機連同一個 Wi-Fi，開 `http://<Mac 的區網 IP>:<port>/`；
  - **Preview**：替 PR #38 的 Preview（不是 Production）設定這兩個變數後重新部署；Preview 受 Vercel 登入保護，手機需能登入。
- **裝置**：至少一台 iPhone（iOS Safari，最新與前一版各一台更好）與一台 Android（Chrome）。記錄機型、OS 版本、瀏覽器版本。
- **確認旗標生效**：`/cs` 的 3D 地圖區塊在 DOM 中有 `data-shared-stage="hex-map"`；在手機上可用 Safari／Chrome 遠端偵錯檢查。不方便偵錯時，以第 1 項的「地圖不閃白、不重畫」作為判斷。
- 每一項記錄：通過／失敗、裝置、時間；失敗時附螢幕錄影。

## 1. World → CS → World

| # | 步驟 | 預期 |
|---|---|---|
| 1.1 | 開 `/`，等世界地圖與群島名牌出現 | 地圖完整，名牌在島上，沒有錯位 |
| 1.2 | 點「程式與資訊群島（CS）」 | 鏡頭飛向 CS，網址變成 `/cs`；地圖不閃白、不出現空白海面或「準備 3D 場景中」 |
| 1.3 | 到達 `/cs` 的瞬間 | CS 地圖從世界畫面接續，位置與大小沒有跳動（模擬器量到 ≤ 0.21 px） |
| 1.4 | 按瀏覽器返回（或 iOS 左緣滑回） | 回到 `/`，第一個畫面就是 CS 地圖在原位，然後飛回整個世界的靜止視角 |
| 1.5 | 重複 1.2–1.4 十次 | 每次都相同；沒有越來越慢、發熱明顯增加或瀏覽器重新載入分頁 |

## 2. 觸控

| # | 步驟 | 預期 |
|---|---|---|
| 2.1 | 在 `/` 單指拖曳地圖 | 平移順暢，放開後停住；拖曳中途不會失效或跳回 |
| 2.2 | 在 `/` 雙指縮放 | 縮放跟手，不觸發整頁縮放 |
| 2.3 | 在 `/cs` 單指拖曳與雙指縮放 | 同上 |
| 2.4 | 在 `/cs` 點一座島 | 聚焦該島，資訊面板出現 |
| 2.5 | 飛行途中（1.2）再點另一個群島或拖曳 | 飛行中斷，沒有卡住或畫面錯亂 |
| 2.6 | 旋轉裝置（直向 ↔ 橫向），在 `/` 與 `/cs` 各一次 | 地圖重新排版、不變形；名牌跟著島 |

## 3. Back／Forward

| # | 步驟 | 預期 |
|---|---|---|
| 3.1 | `/` → `/cs` → 返回 → 前進 → 返回 | 每次都是同一張地圖接續，沒有空白頁 |
| 3.2 | 快速連按返回／前進（約 1 秒內 4 次） | 最後停在正確網址；地圖只有一個，沒有殘留的舊畫面 |
| 3.3 | 直接開 `/cs`，再按「回到世界」 | 世界出現（可能有短暫載入），之後可正常操作 |

## 4. 3D ↔ 清單

| # | 步驟 | 預期 |
|---|---|---|
| 4.1 | 在 `/cs` 切到島嶼清單 | 清單出現，地圖隱藏 |
| 4.2 | 切回 3D | 地圖回來，不重新建立（不閃白） |
| 4.3 | 清單中點一座島 → 前往課綱 → 一堂已發布課程 | 課程頁正常開啟 |

## 5. 背景切換與恢復

| # | 步驟 | 預期 |
|---|---|---|
| 5.1 | 在 `/cs` 切到其他 App 30 秒後回來 | 地圖仍在，可操作；或顯示「3D 地圖已停止」與「重新載入 3D 地圖」按鈕，**不可**停在凍結畫面 |
| 5.2 | 在 `/` 鎖定螢幕 2 分鐘後解鎖 | 同上 |
| 5.3 | 在 `/cs` 開另一個分頁瀏覽其他重度網頁數分鐘，再回來 | 同上 |
| 5.4 | 若出現「重新載入 3D 地圖」，按下它 | 地圖重新出現；不會反覆自動重建 |

## 6. 長時間使用
