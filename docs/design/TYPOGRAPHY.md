# 字體大小標準（2026-11-01）

全站介面的字體大小只使用下列九級，定義在 `src/app/globals.css` 的 `:root`（`--text-*`）。樣式檔一律寫 `font-size: var(--text-sm)`（或 `font: 600 var(--text-xs) ui-monospace, monospace`），不再直接寫 px。

| Token | 大小 | 用途 |
|---|---|---|
| `--text-xs` | 12px | **最小字級**：標籤、標記、說明小字、英文等寬眉標、程式行號、圖例 |
| `--text-sm` | 13px | 次要文字：副標、選單、清單說明、表單標籤 |
| `--text-base` | 14px | 介面內文（`body`）、按鈕、輸入框 |
| `--text-md` | 16px | 閱讀段落（教材內文）、卡片標題 |
| `--text-lg` | 18px | 小節標題（h3） |
| `--text-xl` | 22px | 區段標題（h2）、島嶼名稱 |
| `--text-2xl` | 28px | 頁面標題（h1，手機） |
| `--text-3xl` | 36px | 頁面標題（h1，桌機） |
| `--text-4xl` | 44px | 首頁級主標 |

## 規則

1. **12px 是下限**：繁體中文筆畫多，小於 12px 難以閱讀。需要更小的視覺層級時，改用顏色（`--muted`）、字重、大寫字距，而不是縮小字級。
2. 相對單位（`em`）要夾住下限，例如行內程式碼 `font-size: max(var(--text-xs), 0.9em)`。
3. 例外：SVG 圖表內的文字（`curriculum.module.css` 的 `.svgMark`、`.svgWeight`，以及 `lab.tsx` 的節點編號）使用圖表自己的座標單位，會隨圖表縮放，不套用此表。
4. Tailwind 只用在共用按鈕（`text-sm` = 14px，等於 `--text-base`）。

## 由來

改版前全站有 33 種字級（8～51px），59 處小於 11px（實驗室的格子標籤、圖例、程式行號為 8～9px）。改版時每個字級改為「不小於原值的最近一級」：8～12px → 12px、13 → 13、14 → 14、15～16 → 16、17～19 → 18、20～24 → 22、25～29 → 28、32～38 → 36、40 以上 → 44。程式碼行高由 21px 改為 23px 以配合 12px 程式字。檢查方式：桌機與手機的首頁、`/learn`、`/visualize`、`/learn/array`、`/learn/bfs`、`/curriculum` 與三堂課綱頁，畫面上最小的文字都是 12px，手機沒有水平捲動。
