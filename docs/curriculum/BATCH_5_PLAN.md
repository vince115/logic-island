# 第五批課綱盤點與視覺化策略（PL20）

> 2026-11-20，課程生產流程第五批的 Phase A／B。大綱取自 `docs/planning/data/curriculum-blueprint.json`（標題、目標、概念、先修以藍圖為準，不得偏離）；規格見 [COURSE_CONTENT_SPECIFICATION](COURSE_CONTENT_SPECIFICATION.md)。基準：`main` `fd01b1d`，已發布 99 堂。

## 0. 範圍

第五批只做 PL20「程式語言島綜合挑戰：打造迷你語言」。它是程式語言島最後一堂課；發布後全島 20 堂都已開放，島嶼的課程狀態由「開放中」（`available`）變成「完整」（`complete`），和資料庫應用島寫完時相同。

不改 3D：程式語言島的 `IslandConfig.mapState` 維持 `'planned'`，GLB、座標、P9 相機都不動（課程開放與 3D 視覺狀態分離）。

| | PL20 程式語言島綜合挑戰：打造迷你語言 |
|---|---|

## 3. 確定性與語言版本

- 範例與練習輸出必須確定：不印位址、雜湊順序或計時結果。
- C++ 以 `-std=c++17 -Wall -Werror` 編譯（CI 為 Ubuntu 的 GNU g++，本機為 Apple clang）；Java 以 `--release 17` 編譯；Python 3；JavaScript 為 Node.js。
- 迷你語言的整數運算規則（除法取整方向、除以零）在題目中明定，四語參考解答必須給出相同輸出；不依賴各語言整數溢位行為（題目限制數值範圍）。
- 錯誤訊息格式固定，四語一致，由執行參考解答產生測資的期望輸出。

## 4. 發布後要調整的測試

PL20 原本是測試裡「仍為規劃中的課」的例子。發布後不把 PL20 偽裝回規劃中，也不改成寫死另一堂未來的課（例如 SA20），否則那堂課發布時同樣的問題會再出現。改為從目錄中動態取「目前仍是大綱的課」：

- `tests/world-catalog.test.ts`：取第一堂大綱課檢查沒有頁面；slug 查詢改為對所有大綱課逐一檢查。
- `tests/world-config.test.ts`、`tests/trials-validate.test.ts`、`e2e/sql.spec.ts`：以第一堂大綱課當「沒有頁面／不是完整課程」的例子。
- `tests/world-navigation.test.ts`：PL20 結束程式語言島（`islandComplete`）；「下一堂仍是大綱、不給連結」改由目錄中第一對相鄰的大綱課驗證。
- `e2e/regional-world.spec.ts`：頁面上沒有任何指向大綱課的連結（對所有大綱課檢查）。
- `tests/world.test.ts`：程式語言島的課程狀態為 `complete`，`mapState` 仍是 `'planned'`。

這些測試只在全部 520 堂都發布、目錄裡不再有大綱課時才需要改寫；屆時會以「the catalog still has an outline lesson」的明確訊息失敗，而不是默默通過。驗證器本身（`validateIslandLinks`、`validateTrials`）仍以複製後修改的資料測試，不依賴真實課程狀態。

## 5. 驗證結果（Phase D）

- 內容：8 段、4 範例（lexer、parser、閉包與遞迴、型別檢查各一關）、8 題測驗、練習「迷你語言直譯器」（2 組範例、46 組測資：正常 10、邊界 9、錯誤 27，涵蓋每一種錯誤訊息）。迷你語言先解析整個程式再執行；`#` 之後是註解；除法向零取整；急切求值；錯誤行號是正在執行的敘述。
- 四語程式測試：C++、Java、Python、JavaScript 的 4 個範例與練習（含 46 組測資與範例）全部通過，Java 沒有略過（20 個測試）。C++ 本機以 Apple clang `-Wall -Werror` 編譯，GCC 由 CI 檢查。
- 驗證器 `[]`；發布閘門 100/100；tsc、ESLint 乾淨；Vitest 2528 通過、9 個略過（私有題庫）；production build 產生 100 個課程頁。
- 測驗：8 題的程式逐一以參考直譯器執行，答案與解析相符。原稿 8 題的正確答案都在第一個選項，課程頁不打亂選項，因此重新排列選項（答案位置 2、1、3、0、2、3、1、2），並同步修正解析裡「第幾個選項」的說法。
- 綜合挑戰：`challenge-stages` 依序呈現五關、每關列出用到的課程；元件本身不鎖關卡，「✓ 完成」只表示已瀏覽過的關卡。課程完成仍以測驗全對並讀完為準。新增 E2E（桌機＋手機）：五關順序與課程標籤、最後一關停用「下一步」、重來、PL20 結束本島且沒有規劃中的下一堂、20 堂都完成後課綱顯示「程式語言島全部完成！」。
- 狀態：程式語言島課程狀態 `complete`（20/20），`mapState` 仍為 `'planned'`；全站已發布 100／520；SA20 仍為規劃中。差異只在課綱、測試與文件，沒有改 `src/content/world`、GLB 或座標。
- E2E 旗標關（桌機＋手機）：433 通過；候選頁 2 個像素比對失敗與 main 相同（#36，P9 負責）。
- E2E P9＋區域世界旗標開（p9-prototype、regional-world、island-interactions、world-topology、curriculum、sql）：216 通過、0 失敗。
- 洩漏掃描（分支歷史與 build 輸出）乾淨；前端 bundle 沒有規劃資料。
