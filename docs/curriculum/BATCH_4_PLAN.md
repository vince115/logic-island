## 2. 視覺化策略

| 課程 | 使用的既有視覺化 | 表達方式 | 是否正確表達 |

## 3. 確定性與語言版本

- 所有範例輸出必須確定：不印位址、雜湊順序、計時結果；反射列出成員時先排序（Java `getDeclaredMethods()` 的順序未規定）。
- C++ 以 `-std=c++17 -Wall -Werror` 編譯（CI 為 Ubuntu 的 GNU g++，本機為 Apple clang）；`consteval`、concepts 與 C++26 反射只在正文說明。
- Java 以 `--release 17` 編譯；`javap`、JIT 旗標（`-XX:+PrintCompilation`）的輸出只在正文引用，不當成可執行範例。
- Python 的 `dis` 輸出隨版本改變，只在正文以「某版本的輸出大致如下」引用。
- 效能主張（JIT 比直譯快多少）只說方向與原因，不寫具體倍數。
