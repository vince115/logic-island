# Phase E 課綱規格：60 堂課、三座島

> 狀態（2026-10-31，Phase E.4）：課綱架構完成（E.1）；**完整教材 60／60**：基礎程式島 20／20（F01～F20，E.1 完成 F01～F05、E.2 完成 F06～F20）、資料結構島 20／20（D01～D20，E.3）、**演算法島 20／20**（A01～A20，E.4）。60／60 表示教材內容建置完成，不代表任何學習者已經學完（大綱：學習目標、核心概念、先修、難度、時間、APCS 對應、視覺化類型）。資料來源：`src/content/curriculum/`（`lessons.ts` 為 60 堂的唯一來源；本文件的課程表由它產生，`tests/curriculum.test.ts` 檢查每一堂都列在這裡）。

## 1. 目標與範圍

- Logic Island 從 3D 島嶼展示推進為 DSA／APCS 互動學習平台：每堂課包含觀念說明、C++／Python／Java 三語範例、視覺化（適用時）、觀念測驗、程式練習與學習進度。
- 支援語言固定為 **C++、Python、Java**（三語一致）；C 不作為獨立語言。
- 教材以繁體中文撰寫，專業術語保留英文（如 Stack、Big-O、off-by-one）。
- 三座島各 20 堂、共 60 堂，依建議順序編號：基礎程式島 `F01`～`F20`、資料結構島 `D01`～`D20`、演算法島 `A01`～`A20`。島嶼 ID 與世界地圖一致（`foundations`、`structures`、`algorithms`）。

## 2. 定義

### 2.1 難度

| 難度 | 定義 | 數量 |
|---|---|---|
| 入門（Beginner） | 在先修之上只加入一個新觀念；短程式；以追蹤與直接應用為主 | 20 |
| 中級（Intermediate） | 組合多個觀念、多步驟程式，開始需要複雜度推理 | 31 |
| 進階（Advanced） | 需要設計演算法或說明為何正確、為何夠快 | 9 |

各島分布：基礎程式島 入門 12／中級 8；資料結構島 入門 6／中級 11／進階 3；演算法島 入門 2／中級 12／進階 6。預估總時數：基礎程式島約 890 分鐘、資料結構島約 930 分鐘、演算法島約 1060 分鐘（約 48 小時）。

### 2.2 APCS 對應

APCS（大學程式設計先修檢測）分為觀念題與實作題。每堂課只標示它**幫助準備哪一類能力**：

| 標示 | 意義 |
|---|---|
| 觀念題相關 | 練習程式追蹤、語意與概念判斷 |
| 實作題相關 | 練習讀題、設計與撰寫完整程式 |
| 基礎先修 | 不直接對應題型，但後續兩類都需要（如 F01） |
| 非直接對應 | 與 APCS 無直接關係（目前沒有課程使用） |

**不標示**官方題號、級分、考試範圍或任何成績保證；APCS 的實際範圍與規則以官方公告為準。

### 2.3 先修關係

- 先修只列「直接」需要的課程，可以跨島（例如 `A14` BFS 需要 `D06` Queue 與 `D17` 圖的表示法）。
- 規則：每個先修都必須**在建議順序中排在前面**。因此不可能有循環，而且依順序學習時每一堂都已具備先修（不會有無法解鎖的課程）。
- 先修是學習指引：頁面顯示「建議先完成」與各先修的進度，**不封鎖**任何課程入口。

### 2.4 課程狀態與版本

| 狀態 | 版本 | 頁面呈現 |
|---|---|---|
| 完整教材（complete） | 1.0.0 起 | 全部內容、範例、視覺化、測驗、練習與進度 |
| 規劃中（planned） | 0.x | 只有大綱，明確標示「這一課還在規劃中」，不顯示測驗、練習或互動元件 |

## 3. 對初始規劃的調整

| 調整 | 理由 |
|---|---|
| 演算法島的 **Simulation 移到 A02**（原 A18） | 模擬是 APCS 實作題常見題型、難度低於排序與圖論；放在分析之後就能練習「依規則實作」，也讓後面的課程有實作基礎 |
| A03～A10 依序後移一位（Linear Search → Prefix Sum） | 配合 Simulation 前移 |
| **A11 改為「Recursion 與分治」** | F18 已教遞迴入門，A11 聚焦分治設計、遞迴樹分析與記憶化，避免重複 |
| **A01 演算法分析**以 F19 為先修，聚焦最佳／最差／平均與依資料範圍反推可行複雜度 | 與 F19 的 Big-O 入門分工 |
| 資料結構島維持 Set → Map → Hash Table 的順序 | 先會用集合與 map 解題，再理解雜湊原理，符合初學者的動機順序 |
| 既有六份互動教材（array、stack、queue、binary-search、bubble-sort、bfs）**連結到對應課程**（F11、D02、D05、D06、A04、A05、A14） | 不建立第二套教材系統；規劃中的課程頁可先導向既有互動實驗 |
