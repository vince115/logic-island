### 2.2 特別檢查：第 27 題偽程式碼的語意

```
f(a,b,i) { if(i==0) return (a);
           else { c=a+b; i=i-1;
                  f(c,a,i);
                }
         }
```

- **題目瑕疵**：else 分支呼叫 `f(c,a,i)`，但沒有 `return`。嚴格依程式語意，最外層呼叫在 `i≠0` 時沒有回傳值（在 C 是未定義行為，在 Python 回傳 `None`）。只有最深一層會回傳 13。
- **其他觀察**：
  - 全域的 `a=1; b=1; c=0;` 被參數 `a`、`b` 遮蔽；
  - `c` 是全域變數，每層都會覆寫它，但不影響結果。
- **官方答案** (A) 13，等於「遞迴呼叫加上 return」或「取最深一層的回傳值」的解讀。
- **目前處理**：
  - 依官方答案；
  - `answer.interpretationNote` 記錄這個解讀；
  - 解析也明白寫出「原卷的 else 分支沒有寫 return」。
- **結論**：歧義已揭露，不需要修正題文（題文必須與原卷相同）。這題可能有應考人提出疑義，但考選部沒有更正答案。CSV 的備註欄與答案 PDF 的備註欄都是空的。
