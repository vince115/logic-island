## 1. 官方考試資訊（Task 1）

### 1.1 初級考試科目與能力指標（官方，S3 §1.5、§2.3；S1）

| 科目 | 代碼 | 評鑑主題 |
|---|---|---|
| 科目 1：人工智慧基礎概論 | L11 | L111 人工智慧概念；L112 資料處理與分析概念；L113 機器學習概念；L114 鑑別式 AI 與生成式 AI 概念 |
| 科目 2：生成式 AI 應用與規劃 | L12 | L121 No code / Low code 概念；L122 生成式 AI 應用領域與工具使用；L123 生成式 AI 導入評估規劃 |

**能力指標**（官方原文，S3 §1.5；以下是引用，用於比對考點）：

- 科目 1：
  - 能掌握人工智慧的基本概念與應用領域，瞭解人工智慧的定義、基本理論和核心目標，及 AI 技術在隱私、安全性與倫理層面可能面臨的挑戰。
  - 具備基本的資料處理知識，包括資料收集、清洗、分析和視覺化等過程，並能夠理解資料在 AI 模型中扮演的角色與作用。
  - 理解機器學習的基本原理及其在 AI 中的作用，並熟悉常見的機器學習方法及其應用。
  - 能夠區分鑑別式 AI 和生成式 AI 的特性，並理解生成式 AI 的概念、基本原理及其相關應用。
- 科目 2：
  - 理解 No Code / Low Code 工具的基本概念與應用，掌握其在生成式 AI 應用中的功用和優勢，並能運用工具進行 AI 解決方案的設計與測試。
  - 熟悉生成式 AI 常見工具的基本操作，瞭解其應用領域及適用場景，能有效選擇與應用。
  - 掌握生成式 AI 導入的初步規劃要領，包含需求確認、資源分配、試用測試等步驟等。

## 3. 研究推論（集中列出）

1. 每題配分推論為 2 分（50 題、100 分），不倒扣。
2. 公告試題的上傳日推論自檔名時間戳。
3. 題型越來越偏向情境題，題幹越來越長（§2.1 統計）。
4. 各評鑑主題的出題比重（§2.1 估計）。
5. 學習指引的示範題是圖片。
